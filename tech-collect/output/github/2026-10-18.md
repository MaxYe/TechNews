## ⚠️ 关于「今日 Star 增量」

GitHub Search API **不提供「今日 Star 增量」字段**。真正的 Trending 语义是 **Star 增长速度**，不是总 Star 数。

本脚本采用**快照比对**方案：
1. 抓取「近期新建 + 高 Star」候选集
2. 与最近一次历史快照对比 → 算出 `stars_today`
3. **首次运行无历史快照 → 全部记为 0**（本日即此情况）

因此本日报告列出的是**总 Star 排名**，属于 Trending 的**近似**。
从次日起，历史快照建立后即可输出真实的日增量。

> 数据源标记：`gh_search_total`（按总 Star 排序）

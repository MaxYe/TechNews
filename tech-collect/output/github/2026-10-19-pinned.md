### 核心能力（来自 README）

> **One MCP for reverse engineering across binaries, applications, and runtime behavior.**
> See a feature you like. Understand how it works, down to the binary level.

**能分析的对象**：
- 原生二进制（Native binaries）
- JavaScript / Electron 应用
- .NET 程序集
- 网站

**工作方式**：
1. 让 Agent 用 REA 调查某个功能，**无需源码**
2. REA 连接分析工具，解释功能如何实现，**展示证据**
3. 在你的项目中重建该功能

**技术特性**：
- **本地运行分析**（Analysis runs locally）
- 每个结论都附带**证据与局限性说明**（results include evidence and limitations）
- 可集成已有的 **Hopper / Ghidra / IDA** 安装
- 静态 JavaScript 分析**无需原生分析引擎**

**安装**：
```bash
npx rea-agents setup
```

### 核心能力（来自 README）

> **Turn anything you want to understand, plan, or share into an interactive visual.**

**两种产出形态**：

**① 交互式架构图**
- 描述给 AI Agent → 生成可探索、可定制、可分享的**交互式 HTML**
- 从旅行行程、学习地图，到复杂系统架构
- 生成后可持续追问：「添加认证」「高亮缓存未命中路径」「切换到亮色主题」

**② Explainer（一页式解答）**
- 当答案不只是一张图时，Archify 构建 **explainer**：
  - **结论先行**
  - 每个面板回答一个问题
  - 含表格、步骤、图表、代码和**经过校验的图**

**支持的 Agent 平台**：Cursor、Claude Code、Codex CLI、OpenCode

**安装**：
```bash
npx skills add tt-a1i/archify -g
```

**使用示例**：
```
Use Archify to diagram a web request: Browser calls the API,
the API checks Redis, and a cache miss queries PostgreSQL and fills the cache.
```

**特色**：
- **无需仓库**：可以从一句描述开始，也可以让 Agent 读仓库生成**源码背书的架构图**
- 支持**源码链接追踪**（follow source links, trace a path）
- 17 种图类型、多格式导出（PNG/JPEG/WebP/SVG/WebM）
- 暗/亮主题、追踪动画

### 1. 两个项目都极度活跃

`rea` 与 `archify` **近 7 日均为 100 次提交**（副歌上限），且当日都有推送。这不是「火一阵就凉」的项目。

### 2. 都是「Agent 能力封装」的典型

| 项目 | 封装的能力 | 形态 |
|------|-----------|------|
| rea | 逆向工程（二进制/Electron/.NET/网站）| MCP + CLI |
| archify | 可视化表达（架构图/explainer）| Agent Skill |

**共同点**：不是做 Agent 框架，而是**把某个专业能力封装成 Agent 可调用的工具**。

**这说明 DSH 的插件生态已获得头部 Agent Skills 项目的原生支持。**

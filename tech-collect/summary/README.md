# Summary 目录说明

每日总结与每周总结的存放目录。

## 命名规则

| 类型 | 文件名 | 频次 |
|------|--------|------|
| 每日总结 | `YYYY-MM-DD.md`（如 `2026-10-07.md`） | 每天生成 |
| 每周总结 | `YYYY-MM-DD-weekly.md`（如 `2026-10-11-weekly.md`，日期为当周周日） | 每周日生成 |

## 内容结构

每份总结约 80-120 行，聚合三渠道核心发现：

```markdown
# 技术新闻每日总结 · YYYY-MM-DD

## 🔥 Top 5 信号
## 📦 GitHub Trending（Top 5 + 变化）
## 📰 博客要点（按源聚合）
## 💬 X.com 信号（按生态聚合）
## 🧭 跨源趋势观察（3-6 条）
```

## 生成方式

- 由云端模型读 `tmp/llm-out/{DATE}/*.json`（本地 LLM 已翻译+分类）后产出
- 生成时机在 `run-daily.sh` 完成采集与预处理之后、`scripts/push-daily.sh` 推送之前
